# 🐄 Ферма ПРО — учёт хозяйства

Однострочное приложение (PWA) для учёта личного подсобного хозяйства: коровы, надои, продажи молока, доходы и расходы, корма и рационы, ветеринария, отёлы, привесы, земляника, произвольные направления (мёд, яйца, саженцы и что угодно), отчёты, калькуляторы и аналитика.

## Структура

- `index.html` — всё приложение в одном файле (HTML + CSS + JS, без внешних зависимостей)
- `manifest.json` — манифест PWA (установка на телефон как приложение)
- `sw.js` — service worker (офлайн-режим, кэширование)
- `icons/icon-192.png`, `icons/icon-512.png` — иконки

## Как выложить на GitHub Pages

1. Создайте репозиторий на GitHub (например, `farm-pro`).
2. Загрузите все файлы из архива в корень репозитория (Add file → Upload files), папку `icons` тоже.
3. Settings → Pages → Source: `Deploy from a branch`, Branch: `main`, папка `/ (root)` → Save.
4. Через 1–2 минуты приложение откроется по адресу `https://ВАШ_НИК.github.io/farm-pro/`.

## Как поставить на телефон

Откройте адрес в Chrome (Android) или Safari (iPhone) → «Добавить на главный экран». Приложение будет работать офлайн и выглядеть как обычное.

## Важно про данные

Данные хранятся в localStorage браузера устройства — они не синхронизируются между устройствами. Регулярно делайте экспорт JSON (Настройки → Экспорт) — это единственная резервная копия.
